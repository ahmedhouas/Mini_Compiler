# Compilation

## Description
This project contains exercises and implementations related to compiler construction.

## Requirements
- GCC
- Flex
- Bison
- Linux environment

## Installation
Clone the repository:

```bash
git clone https://github.com/ahmedhouas/Compilation.git
cd Compilation
```

## Usage
Compile and execute the relevant source files according to the instructions provided in each project directory.
